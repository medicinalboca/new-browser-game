# Laser Track Racer

**First-person 3D Forza-style track racer** with racing physics and a futuristic neon laser track.

Built with Three.js (CDN) for instant GitHub Pages play.

## Play Now
https://medicinalboca.github.io/new-browser-game/

## Controls
- **W / ↑** — Accelerate
- **S / ↓** — Brake / Reverse
- **A / D** or **← / →** — Steer

## Physics & Implementation Notes
Car handling and physics follow common, widely-used patterns from public open-source browser racing games (velocity + angle model seen in many GitHub HTML5/Three.js racers). The neon laser track uses emissive-style glowing geometry for that clean futuristic look.
